## 🧠 Loan Eligibility Prediction Project

### 📋 Overview

This project applies **Machine Learning** techniques to predict whether a loan applicant is eligible for loan approval based on financial and demographic data. It helps banks and financial institutions make faster, data-driven decisions by analyzing key borrower attributes such as income, credit history, and property area.

### 🚀 Objective

To build and compare supervised learning models that predict loan eligibility, providing valuable insights for decision-making and improving operational efficiency in loan processing.

### 🧩 Dataset & Preprocessing

* Source: Publicly available online dataset.
* Preprocessing steps included handling missing values, removing duplicates, and encoding categorical variables into numeric form.

### 🛠️ Tools & Technologies

* **Language:** Python
* **Libraries:** Pandas, Scikit-learn, Tabulate
* **Algorithms:** Decision Tree, Naive Bayes, Random Forest

### 📊 Model Evaluation

* **Naive Bayes** achieved the highest recall and accuracy, performing best at identifying eligible applicants.
* **Decision Tree** and **Random Forest** maintained strong overall performance with balanced precision-recall trade-offs.
* The model choice depends on the bank’s priorities—maximizing recall (Naive Bayes) or balancing precision and recall (Random Forest).

### 💡 Results

The comparative study demonstrated that machine learning can streamline the **loan approval process**, reduce human bias, and increase decision accuracy.

### 🧩 GUI Integration

An interactive graphical interface was developed to allow users to input applicant data and receive real-time predictions for loan eligibility.

### 🏁 Conclusion

This project showcases the practical application of **supervised machine learning** in financial analytics. It highlights how data-driven approaches can enhance efficiency and transparency in loan evaluation systems.
